## Getting Started
Steps for setting up the project locally.

### Prerequisites
- Visual Studio
- Node.js v20.19.0+
- Angular CLI
  ```sh
  npm install -g @angular/cli
  ```

## Before creating pull request
- Make sure the project is running without any errors
- Run linting and formatting checks on frontend
  ```sh
  npm run lint
  ```
